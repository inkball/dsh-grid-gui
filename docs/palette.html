状态配色

一层方块的七种状态组合。单个状态用纯色，两种状态沿对角线切成两半（一个角一种纯色，中间空一条），三种状态用纯紫。

仅运行
#4176e6
仅等待
#f59e0b
仅完成
#22c55e

两种状态 · 对角两半

运行 + 等待
蓝 → 淡出 → 无 → 淡入 → 琥珀
完成 + 运行
蓝 → 淡出 → 无 → 淡入 → 绿
完成 + 等待
琥珀 → 淡出 → 无 → 淡入 → 绿

三种状态 · 纯色

三种都有
#a369de

顺序

组合左上右下
运行 + 等待运行等待
完成 + 运行运行完成
完成 + 等待等待完成

为什么两种状态不用混合。混合会把两种颜色平均成第三种，蓝和琥珀平均出来是灰——两种颜色都不是，在灰底上就是一块暗斑。

怎么做的。沿对角线读：一种纯色 → 淡出 → 一条完全无色的带 → 淡入 → 另一种纯色。两种颜色始终没有相遇——第一种在第二种开始之前就已经淡完了，所以中间不会混出第三种颜色。

实测（运行 + 等待，120px 方块的对角线）：
0–28% 纯蓝 #4176e6　·　30–40% 淡出　·　45–55% 完全无色 #ffffff　·　60–68% 淡入　·　70–100% 纯琥珀 #f59e0b

为什么三种状态不用两半。一个方块里挤三种颜色就不再是一眼能读的信息，而这块板子的全部意义就是一眼读完。紫色是唯一没被单色和两两组合占用的色相。

两半格同样有「灯板」提亮。一层方块读成从中心发光的灯板（中心亮、边缘暗），二层会话格是平的——这是区分两层的表面特征，两半格不能例外。但单色格那套「用面色盖住四边」的做法在这里不能用：它会盖掉两个纯色角，还会把中间的空带堵住。所以改成用遮罩挖出中间那块方形，再用 backdrop-filter 提亮，画面本身一点不动，只是往中间变亮。
