状态配色

一层方块的七种状态组合。单个状态用纯色，两种状态用渐变（一个角一种颜色），三种状态用纯紫。

左上蓝 → 右下琥珀
完成 + 运行
左上蓝 → 右下绿
完成 + 等待
左上琥珀 → 右下绿

三种状态 · 纯色

三种都有
#a369de

顺序

组合左上右下
运行 + 等待运行等待
完成 + 运行运行完成
完成 + 等待等待完成

为什么两种状态不用混合。混合会把两种颜色平均成第三种，蓝和琥珀平均出来是灰——两种颜色都不是，在灰底上就是一块暗斑。渐变让方块同时容纳两种颜色：左上角纯的一种，右下角纯的另一种，中间过渡。

为什么渐变在 oklch 里插值。直接走 sRGB 的话，蓝到琥珀的中点会经过一段死灰褐色；oklch 沿色相弧走，全程保持饱和。实测中点：sRGB 是灰，oklch 是品红。

为什么三种状态不用渐变。一个方块里挤三种颜色就不再是一眼能读的信息，而这块板子的全部意义就是一眼读完。紫色是唯一没被单色和两两组合占用的色相。

渐变格没有「灯板」边框。单色格有一圈把边缘压暗的描边，让方块读成从中心发光的灯板。渐变格去掉了它——那圈压暗正好落在两个纯色角上，会把颜色弄脏。
